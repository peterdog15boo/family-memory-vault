# Cinematic media slots

Named placeholder assets for the public cinematic pages.

These are the **drop-in files** the app currently uses. Replace them in place later with final brand photography/video and no code changes will be needed.

## Current slots

- `hero-background.jpg` — landing hero poster / reduced-motion still
- `hero-background.mp4` — landing hero muted loop
- `sign-in-background.jpg` — sign-in / sign-up background
- `section-preserve.jpg` — preserve stage
- `section-private.jpg` — private by design stage
- `section-movies.jpg` — movies stage
- `section-family.jpg` — share with family stage
- `section-legacy.jpg` — peace of mind / legacy stage
- `section-final-cta.jpg` — final CTA stage

## Replacement rule

Keep the filenames exactly the same and overwrite the files here.
The paths are registered in `src/content/landing-media.ts`.

## Quality bar for placeholders/finals

- Warm, human, emotional
- Enough negative space for large type
- No logos or embedded text inside the image
- No empty gray boxes or unfinished frames anywhere in the experience

See `docs/LANDING_MEDIA.md` for the full map.
